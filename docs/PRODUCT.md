# Room — Event Content Sharing Service

Shared experience for collecting, managing, and presenting event memories. Guests upload instantly with no signup; host receives organized archive.

Surfaces: Web/PWA + Backend API + Worker (background jobs). Mobile apps later.
Non-goals: Raw cloud drive; public social network; in Phase 1 no face recognition, no editor.
