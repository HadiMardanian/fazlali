## Narrative
As a Guest I want to join via QR/link with no signup and upload photos/videos with resume so that I contribute in seconds without installing anything.

## Business logic
- Entry: QR scan / link click / event page.
- Identify: display name + accept terms → temporary time-limited session.
- Upload: multi-select, progress %, resume after disconnect, send queue.
- Gallery gated by Room mode; likes/reports where allowed.
