## Narrative
As a Moderator I want to review queued files and enforce privacy controls so that only approved content is visible and abuse is handled.

## Business logic
- Moderated mode queues files pre-publish; approve/reject with audit.
- Controls: PIN, expiring links, session timeout, link rotate, role checks, user/device block.
- Pre-publish: malware scan, GPS EXIF strip, MIME/size limits.

**Status:** todo

**Acceptance**
