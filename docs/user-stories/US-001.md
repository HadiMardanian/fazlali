## Narrative
As an Owner I want to create a Room, pay for retention, share entry kit, and manage/download content so that guest memories arrive organized and preserved.

## Business logic
- Room has name, date, capacity, mode, package, retention.
- Entry kit: unique QR + short link + poster + PIN; link rotatable.
- Expiry notices 7/3/1d; 7-day Grace; then delete/archive.

### US-001-F01 — Create + configure Room
**Status:** done
**Steps**
1. Owner enters name, date, capacity, access/display mode.
2. System creates Room with defaults.
**Acceptance**
- Room persists with mode enforced server-side.

### US-001-F02 — Pay + retention + extend
**Status:** todo
**Steps**
1. Owner selects package (Basic/Wedding/Premium/Archive) + retention.
2. Owner pays; system sets retentionUntil.
3. Owner extends later as needed.
**Acceptance**
- Payment + extension update retention; expiry scheduled.

### US-001-F03 — Entry kit + link rotate
**Status:** done
**Steps**
1. System issues QR, short link, poster, PIN if enabled.
2. Owner rotates/disables link when needed.
**Acceptance**
- Kit unique per Room; rotation invalidates old link.

### US-001-F04 — Manage files + reports + stats
**Status:** todo
**Steps**
1. Owner lists uploads + storage usage + participation stats.
2. Owner deletes/blocks files, handles reports.
**Acceptance**
- Actions audited; blocked content hidden.

### US-001-F05 — Download single + ZIP + notices
**Status:** todo
**Steps**
1. Owner downloads single files or full ZIP (async).
2. System sends 7/3/1d expiry notices.
**Acceptance**
- Downloads via expiring links; notices delivered (channel Unknown).
