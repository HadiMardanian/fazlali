## .۵.۱حالتهای Room

Private
- دسترسی محدود به کاربران دارای لینک یا PIN
- عدم نمایش عمومی گالری
- مناسب برای رویدادهای خانوادگی و خصوصی

- مشاهده فایلهای دیگران غیرفعال است
- مناسب برای جمعآوری خصوصی محتوا

Shared Gallery
- مهمانان میتوانند فایلهای تأییدشده را مشاهده کنند
- امکان الیککردن و تعامل با محتوا وجود دارد
- مناسب برای رویدادهای عمومیتر

Moderated
- فایلها ابتدا در صف بررسی قرار میگیرند
- میزبان یا مدیر محتوا فایلها را تأیید یا رد میکند
- مناسب برای رویدادهای سازمانی ،عمومی و برندها

## .۹ریسکها و راهکارهای کاهش آنها

## .۹.۱اینترنت ضعیف سالن

ریسک :قطع یا ناپایداری اینترنت میتواند باعث شکست آپلود شود.

راهکارها:
- استفاده از صف آپلود ()Upload Queue
- امکان ادامه آپلود
- استفاده از Chunked Upload
- نمایش وضعیت دقیق فایلها
- تالش مجدد خودکار
- ارائه نسخه PWAبدون نیاز به نصب اپلیکیشن

## .۹.۲عدم نصب اپلیکیشن

ریسک :بسیاری از مهمانان تمایلی به نصب اپلیکیشن ندارند.

راهکارها:
- ارائه تجربه کامل در مرورگر
- استفاده از PWA
- ورود از طریق QR Code
- حذف نیاز به ثبتنام مهمان
- طراحی فرآیند آپلود کوتاه و ساده

## .۹.۳حریم خصوصی

ریسک :انتشار ناخواسته عکسها یا دسترسی افراد غیرمجاز.

---
راهکارها:
- ارائه حالت Privateو Upload Only
- استفاده از PIN
- لینکهای انقضادار
- Moderationاختیاری
- گزارش و حذف محتوا
- امکان Blockکاربر
- حذف متادیتای حساس
- اطالعرسانی شفاف درباره نحوه استفاده و نگهداری دادهها

## .۹.۴رشد غیرقابل پیشبینی هزینه ذخیرهسازی

ریسک :افزایش سریع حجم ویدئوها میتواند هزینه زیرساخت را باال ببرد.

راهکارها:
- اعمال سقف مصرف
- تعیین حداکثر حجم فایل
- فشردهسازی و Transcoding
- ارائه بستههای متناسب با مصرف
- حذف خودکار فایلهای منقضیشده
- ارائه گزینه آرشیو پولی
